# Sayo_Star
نظام محادثة صوتية متكامل وآمن، مصمم هندسياً لتقديم تجربة تواصل حي (Real-time Audio Streaming) بأقل معدل تأخير (Low Latency). يعتمد النظام على بنية برمجية حديثة تم تطويعها لمعالجة تدفق الصوت بوضوح عالي، مع ربط الواجهات الأمامية (Frontend) المبرمجة بلغة Flutter مع خوادم خلفية مدارة بالكامل لضمان استقرار الاتصال وحماية البيانات.
